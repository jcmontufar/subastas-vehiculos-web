# Activos demostrativos

Estas 30 fotografías sintéticas fueron generadas específicamente para la demostración académica de AutoPujo mediante la herramienta de generación de imágenes de OpenAI el 2 de octubre de 2026.

- No proceden de catálogos de terceros ni contienen datos personales.
- No incluyen texto, marcas de agua, matrículas legibles ni logotipos intencionales.
- Cada carpeta corresponde a un vehículo del seed y contiene cinco vistas: frontal, trasera, perfil, interior y motor.
- El script `scripts/seed-demo.mjs` las publica únicamente en rutas marcadas como `autopujo-academic-demo-v1`.

Son material de demostración; no representan vehículos reales ofrecidos para venta.
